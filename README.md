# Rene Emezi — Portfolio

Simple static portfolio site for Rene Emezi, Backend Developer.

**Live site:** https://rene0115.github.io/rene-emezi-portfolio/

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

Then visit the URL shown in the terminal (usually `http://localhost:3000`).
